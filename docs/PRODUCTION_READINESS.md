# 生产就绪评估

## 已由当前仓库完成

| 领域 | 状态 | 证据 |
|---|---|---|
| 业务闭环 | 完成 | 识别、规则、PASS/REVIEW/REJECT、人工复核、追溯 |
| 身份与权限 | 完成（本地账号） | 四级 RBAC、密码摘要、复杂度、锁定、会话撤销 |
| 订单与复核并发 | 完成 | 订单状态机、复核原子认领、记录版本递增 |
| 工位身份 | 完成 | 哈希 API Key、一次性显示、轮换、心跳、版本上报 |
| 证据安全 | 完成（本地存储） | SHA-256、不透明名称、鉴权读取、访问审计、路径越界防护 |
| 审计完整性 | 完成 | 请求上下文、前向哈希链、可选 HMAC、完整性校验接口 |
| 输入防护 | 完成 | 流式 10 MiB 限制、真实格式、像素、多帧、规则预校验 |
| 可观测性 | 完成（单节点） | JSON 日志、请求 ID、健康探针、Prometheus 指标、延迟分位数 |
| 数据可靠性 | 完成（单节点） | SQLite WAL、迁移、在线备份、完整性及 SHA-256 校验 |
| 供应链门禁 | 完成 | CI、覆盖率、Ruff、pip-audit、CodeQL、Dependabot、非 root 镜像 |
| 外部集成可靠性 | 完成基础 | 事务型 Outbox、领域事件、待处理查询和幂等确认 |

## 只能在目标企业环境完成

| 外部条件 | 原因 | 接入目标 |
|---|---|---|
| PostgreSQL/Redis/MinIO | 需要企业基础设施、凭据和容量设计 | 多实例事务、分布式限流、对象证据存储 |
| OIDC/LDAP/AD | 需要企业身份提供方 | 单点登录、组织和工厂级数据授权 |
| 真实 OCR 验收 | 需要真实标签、相机、光源和标注真值 | 完整 SN 识别率、字段 F1、P95 时延 |
| MES/QMS/ERP/WMS | 需要接口协议和测试环境 | 基于现有 Outbox 完成签名投递、工单同步、不合格单、冻结和放行 |
| PLC/工业相机 | 需要硬件和产线安全评审 | 触发采集、节拍控制、物理拦截 |
| 高可用与灾备 | 需要集群、网络和恢复目标 | 多副本、RPO/RTO、跨节点演练 |

因此，当前代码可作为企业单机试点和多工位系统的参考实现；在没有上述外部条件和现场验收前，不应宣称已经达到无人值守量产标准。
